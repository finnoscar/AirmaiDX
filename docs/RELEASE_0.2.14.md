# AirmaiDX 0.2.14 (24)

First public preview for Apple silicon Macs running macOS 15 or later.

- Open a game from its existing folder or an external SSD.
- Follow in-app setup for missing prerequisites and game configuration.
- Use the current display, controller, chart library, and iPhone reader tools.

Download the DMG and its SHA-256 file, then drag AirmaiDX into Applications. On first setup, choose **Download and Install** to retrieve the Windows runtime directly from its publishers. Rosetta 2 is required. The app is ad hoc signed and is not notarized.

No game files, accounts, credentials, or runtime downloads are included in the DMG. AirmaiDX is an independent project and is not affiliated with SEGA.
